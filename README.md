# 💨 Real Smoke

**Real Smoke** adds grounded, industrial smoke ambience to Factorio so your factory feels dirtier, heavier, and more alive.

Instead of everything looking perfectly clean and static, working machines, burner equipment, vehicles, rockets, and explosions can now produce more believable smoke effects that fit the normal Factorio style.

Build dirtier. Feel more industry. Keep your factory looking active without turning the whole map into a giant smoke cloud.

## ⚙️ What It Does

Real Smoke adds extra visual-only smoke ambience to industrial parts of the game.

Smoke can appear from working boilers, furnaces, burner mining drills, moving vehicles, rockets, and explosions. The effect is designed to feel heavier and more believable than vanilla, while still staying clean enough for normal gameplay.

The goal is not to cover the whole base in thick fog. The goal is to make factories feel more mechanical, more active, and more alive.

This version also supports optional interaction with other compatible mods:

* **Real Rain** can make smoke feel wetter and slightly thinner during rain
* **Real Wind** can push and drift smoke more during gusts and storms
* **Real Steam** can sit alongside Real Smoke for a fuller industrial atmosphere

Real Smoke still works perfectly fine on its own if those mods are not installed.

## 🛠️ Settings

Real Smoke includes runtime settings so you can tune the look and performance to match your game.

| Setting                        | What It Does                                                           |
| ------------------------------ | ---------------------------------------------------------------------- |
| **Enable Real Smoke**          | Master switch for all Real Smoke effects                               |
| **Smoke Density**              | Controls how much smoke appears                                        |
| **Smoke Smoothness**           | Controls how often smaller smoke puffs are emitted                     |
| **Black Smoke Strength**       | Controls how dark and heavy soot smoke appears                         |
| **Smoke Scan Radius**          | Controls how far around players the mod checks for valid smoke sources |
| **Machine Smoke**              | Enables smoke for working industrial machines                          |
| **Vehicle Smoke**              | Enables exhaust smoke for moving locomotives, cars, and tanks          |
| **Rocket and Explosion Smoke** | Enables smoke bursts for rockets and explosions                        |
| **Debug Smoke Stats**          | Prints smoke spawn stats for testing                                   |

## 🌫️ Smoke Density Options

| Option        | Description                                                  |
| ------------- | ------------------------------------------------------------ |
| **Subtle**    | Very light smoke, best for large factories or weaker systems |
| **Balanced**  | Recommended default; visible but not messy                   |

| **Cinematic** | Maximum smoke for screenshots and dramatic factory builds    |

## 🎞️ Smoke Smoothness Options

| Option            | Description                                                |
| ----------------- | ---------------------------------------------------------- |
| **Performance**   | Lowest runtime cost with less frequent smoke               |
| **Smooth**        | Recommended normal gameplay setting                        |
| **120 FPS Style** | More fluid-looking smoke with smaller, more frequent puffs |
| **Ultra Real**    | Smoothest visual preset with more layered smoke behaviour  |

**Note:** These are visual smoothness presets only. Factorio still runs at its normal simulation rate.

## 🧪 Behaviour Notes

* Machines only emit smoke while they are actually working
* Vehicles only emit exhaust smoke while moving
* Rocket and explosion smoke is short and event-based
* Smoke is spawned near active players to help keep the mod practical
* Rain can make smoke look slightly thinner when **Real Rain** is installed
* Gusts and storms can push smoke harder when **Real Wind** is installed
* The mod is visual-only and does not affect recipes, stats, pollution, or progression

---

## 🔗 Compatibility

Real Smoke is designed to work well by itself, but it can also optionally interact with other mods in the Real series.

### Works on its own

You do **not** need any other mod installed for Real Smoke to work.

### Optional linked behaviour

If other compatible mods are installed, Real Smoke can react to them automatically:

* **Real Rain**
  Rain can soften or thin heavy smoke slightly so wet weather feels more natural.

* **Real Wind**
  Wind and storms can push smoke harder, adding more sideways drift and movement.

* **Real Steam**
  Pairs well visually with Real Steam for fuller industrial ambience across steam and smoke systems.

This keeps the mod flexible:
**great alone, even better together.**

## 📌 Design Goal

The aim of Real Smoke is to make Factorio feel more alive without going too far.

It is meant to sit somewhere between vanilla Factorio and a more cinematic industrial look:

* More active than vanilla
* More believable than random smoke everywhere
* Still clean enough for normal gameplay
* Tunable for performance or atmosphere
* Stronger when combined with the other Real mods
